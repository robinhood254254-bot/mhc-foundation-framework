# 3. COLOR DIRECTION

The website should have a **light, clean, premium, modern visual identity**.

Prioritize:

* Light backgrounds
* White or very-light neutral surfaces
* Soft brand-supported tones
* Strong but controlled text contrast
* Clean sections
* Professional spacing
* Subtle visual depth

Avoid an overly dark website.

Avoid excessive gradients.

Avoid generic blue hospital styling unless the supplied logo clearly requires it.

Use darker colors mainly for:

* Text
* Navigation
* Important contrast
* Selected UI elements
* Secondary visual accents

The interface should feel calm, premium, trustworthy, and technologically modern.
